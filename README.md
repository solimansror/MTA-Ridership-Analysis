# MTA Ridership Analysis Dashboard 🚇📊

## 📌 Overview
This project analyzes daily ridership data from the New York Metropolitan Transportation Authority (MTA) to understand how public transportation usage changed after COVID-19.

The dashboard focuses on identifying recovery trends, behavioral shifts, and transportation patterns using Power BI.

---

## 🚨 Problem Statement
COVID-19 caused a major disruption in public transportation systems worldwide.

This project aims to analyze how MTA ridership changed before and after the pandemic, measure recovery levels, and understand the new commuting behavior patterns.

---

## 🎯 Objectives
- Analyze ridership trends before and after COVID-19
- Measure recovery across different transportation modes
- Identify weekday and weekend travel behavior
- Detect the “Friday Effect” caused by hybrid work
- Provide insights to support transportation planning

---

## 🛠 Tools Used
- Power BI
- DAX
- Excel / CSV

---

## 📊 Key Insights
- Ridership dropped by approximately 41% after COVID-19
- Public transportation recovery is slower than private vehicle traffic
- Tuesday–Thursday became the peak commuting days
- Friday shows a noticeable decrease in ridership (“Friday Effect”)
- Weekend recovery is stronger due to leisure travel
